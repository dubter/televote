# Televote Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: используй superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans. Шаги помечены чекбоксами.

**Goal:** Бэкенд анонимного голосования под пик ТВ-эфира: приём голоса за один атомарный вызов Redis, дедуп без регистрации, админка, стенд одной командой.

**Architecture:** Голос — атомарный `EVALSHA` в Redis Cluster (дедуп и инкремент слиты, ключи в одном слоте через hash tag). Postgres — только control plane, вне горячего пути. Снапшотер раз в 5 с сворачивает шарды и пишет итог в Postgres.

**Tech Stack:** Go 1.26, rueidis v1.0.77, pgx v5.10.0, chi v5.3.2, goose v3.28.0, OTel v1.46.0, testcontainers v0.44.0, docker-compose.

**Spec:** `docs/design.md`, требования `docs/requirements.md`

## Global Constraints

- Go 1.26; версии библиотек — таблица в `design.md` §18, пинуются точно
- Зависимости однонаправленные: `domain ← application ← adapters`; проверяется `depguard`
- `ctx` первым параметром, таймаут на каждом внешнем вызове
- Ошибки — типизированные доменные; **единственная** точка маппинга в HTTP-коды
- Никаких глобалов и `init()`; конструкторы `New*(deps…) (*T, error)`
- Интеграционные тесты Redis — **только на кластере** (single-node скрывает `CROSSSLOT`)
- Логи `slog` в JSON с `trace_id`; на горячем пути только сэмпл и ошибки
- Секреты из env, дефолтные креды — ошибка старта при `ENV=production`
- Каждая задача завершается коммитом; тест пишется до реализации
